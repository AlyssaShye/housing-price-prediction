# 🏡 Housing Price Prediction Using Multiple Linear Regression

## Overview

This project uses multiple linear regression to predict residential housing prices based on property characteristics and neighborhood features. The objective was to develop a predictive model that accurately estimates home values while identifying the variables that have the greatest influence on housing prices.

---

## Business Problem

Accurately estimating housing prices is important for buyers, sellers, real estate professionals, and financial institutions. The goal of this project was to build a predictive model that analyzes housing data and identifies the factors that most strongly influence property values, allowing stakeholders to make more informed decisions.

---

## Objectives

- Clean and prepare the housing dataset for analysis.
- Explore relationships between housing features and sale price.
- Build a multiple linear regression model.
- Evaluate model performance using statistical metrics.
- Identify the variables that contribute most to predicting housing prices.

## Results

The final regression model identified several property characteristics that significantly influence housing prices. Model performance was evaluated using statistical measures including R² and Root Mean Squared Error (RMSE), demonstrating the model's ability to explain variation in housing prices and generate accurate predictions.

---

## Business Value

Predictive models such as this can assist real estate professionals, financial institutions, and prospective buyers by providing objective estimates of property values. Understanding which housing characteristics have the greatest impact on price supports more informed pricing strategies and investment decisions.
